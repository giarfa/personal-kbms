# US-001 — Manual test handoff

Automated coverage (`php artisan test`, `NORMAL` bar) is in `tests/Feature/`. No Playwright, Dusk, Pest browser, or viewport-matrix suite exists at this bar — the following need a human pass at `http://personal-kbms.test`.

## Keyboard-only pass

- Load the Agenda page with no mouse. First `Tab` must land on the "Skip to content" link (`.kb-skip`), visible on focus.
- Activating the skip link moves focus into `#main`.
- Tab through the sidebar nav (Agenda, Calendar), then into the header controls (mobile sidebar toggle, theme button). Every stop must show a visible focus ring — never outline-only, never suppressed.
- Navigate to the placeholder Agenda and Calendar pages via keyboard only; both must be reachable and readable.

## Theme toggle

- Click the sun/moon icon in the header. Confirm the whole shell (sidebar, header, page background) flips between light and dark.
- Reload the page — the chosen appearance must persist (Flux's `@fluxAppearance` setting), not reset to a default.
- Toggle back and forth a few times to confirm no flash of the wrong theme on load.

## 375 px pass (mobile.html checklist)

Compare against `.larapilot/mockups/kbms-app/mobile.html`:

- Sidebar collapses behind the mobile toggle; opening it does not clip content or break scroll.
- Touch targets (toggle, theme button, nav items) are comfortably tappable (≥ 44 px).
- Agenda/Calendar headings and body text remain readable with no horizontal scroll on the shell itself.

## No-login-prompt confirmation

- Visiting `/` and `/calendar` never shows a login form, avatar, or "Log out" affordance.
- `/login` returns a 404 page.

## SQLite-missing check

- Stop the app, rename `database/database.sqlite` away, reload `http://personal-kbms.test/` with `APP_DEBUG=true` — confirm the actionable "SQLite database file is missing" page (not a stack trace), naming the `touch` + `migrate` remedy.
- Restore the file and confirm the site serves normally again with no cache clearing needed.
