## Lars (security)

- [High] `app/Calendar/IcsParser.php` (`event_url` from the feed's `URL` property, and `join_url` from `X-MICROSOFT-SKYPETEAMSMEETINGURL`) had **no scheme validation**. This spec is what first renders both as clickable `href`s (`resources/views/components/meeting/external-links.blade.php`) — a compromised/malicious ICS feed could set `URL:javascript:...` or a similar dangerous scheme, producing a clickable "Open in Outlook"/"Join Teams meeting" link that executes attacker JS in the app's origin. **Fixed:** `OutlookLinkBuilder::isSafeUrl()` now allow-lists `http`/`https` via `parse_url(...)[scheme]` for both `event_url` (falls through to the template/unavailable outcome when unsafe) and `join_url` (returns `null` when unsafe). Covered by two new unit tests (`test_a_dangerous_event_url_scheme_is_rejected_and_falls_back_to_the_template`, `test_a_dangerous_join_url_scheme_is_rejected`).
- [Informational] Occurrence-key decoding (`OccurrenceKey::fromRouteKey`) and the route-bound query (`CalendarEvent::scopeForOccurrence`) are injection-safe — decoded bytes flow through Eloquent's parameterized `where()`, never raw SQL; malformed/unknown keys 404 via `firstOrFail()`.
- [Informational] Feed-mirrored fields (`summary`, `description`, `location`, `organizer`, `attendees`) render exclusively through Blade's `{{ }}` auto-escaping — no `{!! !!}` anywhere in the new views.
- [Informational] Clipboard copy buttons (`mirror-panel.blade.php`) use `@js()` correctly for JS-context escaping of `source_uid`/`recurrence_id`.
- [Informational] No new dependencies (`composer.json`/`composer.lock` unchanged) — `composer audit` not newly relevant.
- [Informational] No auth bypass — the new `meetings/{occurrence}` route sits behind the same loopback-only gate as every other route; no middleware weakened or skipped.

**Verdict: GO (after the event_url/join_url scheme fix)**
