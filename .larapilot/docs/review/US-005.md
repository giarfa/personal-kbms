## Lars (security — rework pass)

Verdict: **GO**. `composer audit` clean; no new dependencies.

- [Informational] `catch (Exception)` is genuinely total. An 8,000-case fuzz over date-parser tokens plus 19 targeted hostile strings (relative expressions, `@epoch` overflow, 16 KB of chained `+1 year`, embedded NUL, `<script>`, negative and 16-digit years) produced **zero** non-`Exception` throwables and **zero** parses over 50 ms. Thirteen hostile query strings through the real HTTP kernel all returned 200, including `?date[]=…` and `?date[a]=b` (no `TypeError` on the `?string` property). `previous`/`next`/`today` are likewise total.
- [Informational] The `??=` → `=` change in `mount()` is a **net security gain**: the raw attacker string no longer survives into the Livewire snapshot. With `?date="><img src=x onerror=alert(1)>` the payload appears in the body neither raw nor entity-encoded, and `wire:snapshot` holds only `{"data":{"date":"2026-09-08"}}`. Since `app.debug` is true under `app.env=local`, making the index route total also removes the Ignition stack-trace disclosure `?date=not-a-date` used to render.
- [Informational] `AgendaRow::durationMinutes` — Carbon 3's `diffInMinutes()` returns a float, so any duration not an exact multiple of 60 seconds raised `Implicit conversion from float 1.5 to int loses precision` (`E_DEPRECATED`) and rendered the wrong minute; a one-second event became `0 min`. Never observable in practice — `LOG_DEPRECATIONS_CHANNEL` is pinned to `null`, `phpunit.xml` sets no deprecation failure mode, and it never reaches the response body — but the diff routes many more events through the line. **Fixed** in `f916649` by rounding.
- [Low] The widened clamp hands the feed a "pin to day one" primitive: 50 rows spanning `1000-01-01 → 9999-12-31` give per-day counts `50,0,0,0,0,0,0` at every anchor. Correct behaviour for a legitimately long event, and `SyncCalendarFeed` bounds how many events are stored (±90/180 days) though not their span; `AgendaQuery` has no `limit()`. Render cost, not a vulnerability. **Open, accepted.**
- [Low] Extreme anchors (year 1002026, year −3166904) return 0 rows cheaply, but only because both the PHP clamp and SQLite's `starts_at < :to` are *lexicographic* string comparisons that break outside 4-digit years — accidentally safe rather than deliberately bounded. A ±5-year sanity clamp on `?date` would make the page honest. **Open, accepted.**
- [Informational] The `catch` handler itself calls `AgendaRange::today()` → `now(config('kbms.timezone'))`, so a garbage `KBMS_TIMEZONE` would throw from inside the catch. Reasoning only, not reproduced; exposure nil, since `config/app.php` reads the same env var and the app would already be failing app-wide.
- [Informational] No new escaping surface. Zero `{!! !!}` in `resources/views`; all three new output paths render Carbon `format()` output derived from `datetime`-cast columns rather than feed text, through `{{ }}`. `starts_at`/`ends_at` are `NOT NULL`.
