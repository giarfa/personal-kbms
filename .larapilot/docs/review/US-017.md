Deliberate per the code's own docblock ("no size bound by design"); negligible risk in a single-operator loopback tool. Left as-is.
- [Low] Theoretical TOCTOU window between `verify()` and the subsequent read/`response()->file()` — not exploitable in a single-operator local context. Left as-is.
