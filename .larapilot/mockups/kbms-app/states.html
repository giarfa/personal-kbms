Transcript link — US-007

Six states, and the distinctions between them are the spec. “Missing”, “unreadable” and “unconfigured” must not collapse into one message.

Linked by convention Pattern matched a single readable file.
Linked manually Operator's choice. Always wins over the convention, and a pattern change cannot dislodge it.

⚠ File exists but is not readable Permission denied on 2026-09-02-1100-1-1-sara.md. This is reported distinctly from a missing file, because the fix is different: chmod, not relink.

Transcripts directory not configured

Set KBMS_TRANSCRIPTS_PATH in .env and re-run php artisan kbms:doctor. A configuration prompt — not an error page.

Bounded read A 40 MB transcript renders its first bounded chunk with “showing first 2 MB — open the file for the rest”. Reading is never unbounded.
Rejected A resolved path escaping KBMS_TRANSCRIPTS_PATH (via pattern or manual input) is refused outright, whether or not the file exists.

Launch bridge — US-009

Every blocked path states which precondition failed and which configuration key fixes it.

⌘ Enter to launch Launcher ready Transcript linked, script present and executable.
Blocked No transcript linked — there would be no context file to pass as argument one. Link a transcript first.
Blocked KBMS_CLAUDE_LAUNCHER is not configured.
Blocked Script found but not executable: chmod +x /Users/operator/bin/kbms-claude.sh

Type a question first — whitespace only is rejected before anything is dispatched.

Dispatched Queued job accepted. The terminal window is owned by the OS: quitting queue:work does not close the operator's session.
⚠ Launcher exited 127 Recorded on the launch row and shown here. Copy the invocation below and run it in a terminal to see the script's own output.

Adversarial question text stays one argument — this is the security-critical criterion:

/Users/operator/bin/kbms-claude.sh
  '/Users/operator/Recordings/transcripts/2026-09-07-0930-q4-roadmap-review.md'
  'What did $(whoami) decide; also `rm -rf ~`, and "why"?
Include the second line too.'

Built as an array. Nothing above is interpreted by a shell — the script receives it verbatim as $2.

Contract for Anne Each block above maps to a named acceptance criterion. The wording matters as much as the layout: “never synced” ≠ “stale”, “missing file” ≠ “unreadable file”, “not configured” ≠ “configured but invalid”. Feature tests should assert the distinguishing string, not just a non-200 or a generic error class.
